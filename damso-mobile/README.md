# 담소 React Native 앱

Expo SDK 56 / React Native 0.85.3 / React 19.2 / TypeScript. 같은 화면을 React Native Web에서도 확인합니다.

## 실행

1. `damso-server/backend`에서 `.venv/Scripts/python.exe -X utf8 scripts/run-local.py`로 PostgreSQL·API·AI 워커를 실행합니다.
2. 저장소 루트에서 `powershell -ExecutionPolicy Bypass -File scripts/start-damso-preview.ps1`을 실행합니다.
3. <http://localhost:8081>에서 첫 설정 → 가입/로그인 → 가족 연결을 진행합니다.

기존 포트의 프로세스를 강제로 종료하지 않습니다. 수동 실행은 `damso-mobile`에서 `npm run web`, `damso-library`에서 `npm run web:dev`입니다. 처음 설치할 때는 각 폴더에서 `npm ci`를 실행합니다.

`EXPO_PUBLIC_API_URL` 기본값은 `http://127.0.0.1:8000`입니다. 실물 휴대폰에서는 개발 PC의 LAN 주소 또는 배포한 HTTPS API 주소를 지정하고 서버의 허용 origin과 바인딩도 맞춰야 합니다. AI 키와 DB 비밀번호는 Expo 공개 환경변수에 넣지 않습니다.

## 화면과 API 연결

| 화면 | 연결된 기능 |
| --- | --- |
| 첫 설정·계정 | 부모/자녀 선택, 호칭 안내, 이메일 가입·로그인, 로그인 복원 |
| 가족 연결 | 6자리 코드 발급·재발급, 만료 시간, 상대 확인 후 연결, 대기 상태 갱신, 연결 해제 |
| 오늘의 질문 | 역할별 기본·개별·추가 질문 조회, 다른 질문 선택, 음성·글 답변, STT→LLM 처리 확인·재시도, 현재 질문의 초안 복구, 제목·요약 수정 후 공개, 재답변·건너뛰기 |
| 기억의 서재 | 가족 이야기 조회·역할 필터·페이지 추가 조회, 상세 직접 조회, 원문·원음 선택 공유·청취, 사진 등록·확대·삭제, 댓글 작성·본인 댓글 삭제, 공감·취소, 본인 이야기 삭제 |
| 가족 앨범·3D | 같은 가족 사진 조회, 기존 GLB 공간 로딩, 책에서 이야기 목록·액자에서 가족 앨범으로 이동 |
| 설정 | 이름·글자 크기·요약 문체·부모님 호칭 서버 저장, 알림 수신 여부·희망 시간 저장, 비밀번호 변경, 로그아웃, 탈퇴 확인 |
| 직접 질문 | 부모가 자녀에게 오늘~30일 뒤 질문 전송, 목록·추가 조회, 미답변 질문 취소 |
| 새 소식 | 앱 내부 알림 조회·추가 조회, 읽음 처리, 이야기·가족·질문 화면 이동 |

기본·개별·AI·가족 예약을 합해 하루 최대 3개입니다. AI 꼬리질문은 하루 최대 1개, 가족의 ‘더 궁금해요’ 요청은 다음 날 1개만 예약합니다. 제한은 서버와 DB에서 검사합니다. 답변은 작성자 확인 후 즉시 공개하며 상호 답변 잠금은 없습니다.

로그인 전 미리보기를 선택하면 예시 데이터를 구분해 보여줍니다. 로그인 후에는 예시를 섞지 않으며 가족 연결 전에도 본인 기록은 조회할 수 있습니다. 미리보기로 작성한 글은 실행 중에만 보관합니다.

## 로그인과 데이터 보호

- Access token은 메모리에, refresh token은 Android/iOS의 Expo SecureStore에 보관합니다. 웹은 현재 탭의 sessionStorage를 사용합니다. 웹 저장소는 OS 보안 저장소와 같지 않습니다.
- 만료된 토큰은 자동 갱신하고 동시 갱신 요청은 하나로 합칩니다. 로그아웃은 서버 세션을 폐기합니다. 계정 전환·로그아웃 뒤 도착한 이전 응답은 버립니다.
- 원문·원음은 작성자가 선택한 항목만 상대에게 공개합니다. 음성·사진 URL에 토큰을 넣지 않고 인증 헤더로 읽습니다. 웹 원음은 인증된 임시 Blob으로 재생합니다.
- 가족 연결 해제·이야기 삭제·사진 삭제·탈퇴는 확인 단계를 거칩니다. 역할은 가입 시 선택하며 연결된 계정에서 미리보기 역할로 전환하지 않습니다.
- 가족 호칭·작성자 이름은 서버가 반환한 표시값을 사용하며 본문 전체를 문자열 치환하지 않습니다.

## 문체·글씨체·3D

요약 기본값 `auto`는 ‘녹음된 평소 말투와 비슷하게 요약해요’입니다. 설정에서만 `diary`(담백한 일기)로 고정할 수 있습니다. 이전 기록·원문은 다시 쓰지 않습니다.

이야기 본문만 손글씨 3종을 사용하고 작은 T 버튼으로 순환합니다. 페이지를 다시 열면 첫 기본 글씨로 돌아옵니다. 앱에는 실제 폰트 이름을 표시하지 않습니다. 출처는 `assets/fonts/StoryHandwriting-SOURCES.md`, 라이선스는 같은 폴더에 있습니다.

기존 `damso-library`의 GLB·Three.js 장면을 웹 iframe/네이티브 WebView로 표시합니다. `EXPO_PUBLIC_LIBRARY_3D_URL`로 배포한 뷰어 주소를 지정할 수 있습니다. 웹 기본값은 현재 호스트의 5174 포트, Android 에뮬레이터 기본값은 `10.0.2.2:5174`입니다. 웹 메시지는 origin과 iframe window를 함께 확인합니다. 액자 표면의 사진 텍스처는 예시이며 실제 가족 사진은 연결된 앨범에서 조회합니다.

## 검증과 남은 범위

검사 명령: `npm test`, `npm run typecheck`, `npm run lint`, `npm run export:web`. 백엔드 검사는 별도 `damso_test` DB만 사용하는 `scripts/test-backend.py`로 실행합니다.

2026-10-21 연결 작업에서 모바일 단위 검사 18개와 백엔드 통합 검사 85개가 통과했습니다. 브라우저 검증은 별도 테스트 API와 가상 가족 데이터를 사용하며 실제 사용자 DB·AI 키를 사용하지 않습니다. 준비된 요약 초안으로 화면 공개 흐름을 검사하는 것은 새 STT·LLM 실호출 평가와 구분합니다.

남은 기능은 TTS·목소리 복제, 휴대폰 푸시·예약 알림 발송, 이메일 비밀번호 복구 화면입니다. 희망 알림 시간은 저장하지만 예약 발송으로 표시하지 않습니다. Android/iOS 실기기의 보안 저장·녹음·사진 선택·원음 청취 및 네이티브 빌드는 별도 확인이 필요합니다.

Expo 전이 의존성의 기존 보안 경고(높음 19, 보통 10)는 이번 연결 작업에서 강제 버전 변경하지 않았습니다. 외부 배포 전 SDK 보안 패치와 영향 범위를 확인해야 합니다.
