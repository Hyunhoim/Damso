# STT 연동과 합성 전사문 LLM 실호출

검증일: 2026-10-20 · HCX-007 · damso-v1.4

아래는 합성 전사문 8개 중 무작위로 고른 3개를 실제 HCX API에 보낸 결과입니다. 실제 음성을 전사한 결과가 아니며 CLOVA Speech API는 호출하지 않았습니다. 요약과 질문은 모델의 원문 출력입니다.

## 가족과 통화한 일상

질문: 오늘 가족과 나눈 이야기가 있나요?

입력: 딸하고 십 분쯤 전화했어요. 새로 이사한 집 이야기를 들었는데 주소는 아직 몰라요. 다음 달에 사진을 보내준다고 했어요.

> 딸과 십 분 정도 통화하며 새로 이사한 집에 대한 이야기를 나누셨다고 해요. 딸이 다음 달에 사진으로 집을 보여주기로 했다고 해요.

꼬리질문: 딸이 보내주기로 한 사진은 어떤 모습일까요?

## 자녀의 음식 이야기

질문: 오늘 먹은 음식 중 기억에 남는 것은 무엇인가요?

입력: 점심에 김치볶음밥을 먹었어요. 아버지가 해주시던 맛이랑은 좀 달랐어요. 주말에는 제가 직접 만들어 보려고 해요.

> 점심에 김치볶음밥을 드셨다고 해요. 아버지의 맛과는 조금 달랐다고 하시며, 주말에는 직접 만들어 보실 계획이라고 해요.

꼬리질문: 김치볶음밥을 만들 때 어떤 재료를 추가하실 건가요?

## 대화 중단

질문: 오늘 하루는 어떠셨나요?

입력: 집에서 책을 조금 읽었어요. 오늘은 더 이야기하고 싶지 않아요.

> 오늘은 집에서 책을 조금 읽으셨다고 해요.

꼬리질문: 없음

세 응답 모두 서버의 JSON 형식 검증을 통과했습니다. 의미 정확성과 원문 보존은 별도 검토 대상이며 이 소수 사례는 정확도 평가가 아닙니다.

원본 JSON (Git 제외): `data/llm-tests/20261019T152931-transcripts.json`

## 원문 대조 검토

- 세 사례 모두 작성자 이름을 주어로 넣지 않고 해요체로 출력했습니다.
- 통화 사례는 10분·딸·새집·다음 달 사진을 유지했으나, 주소를 아직 모른다는 정보가 빠졌습니다. 꼬리질문도 실제 경험보다 미래 사진을 상상하도록 묻는 형태여서 개선 여지가 있습니다.
- 음식 사례는 김치볶음밥·아버지의 음식과 맛 차이·주말 계획을 유지했습니다.
- 대화 중단 사례는 독서만 요약하고 추가 질문을 만들지 않았습니다.
- 따라서 형식 3/3 통과와 의미 보존 품질을 구분합니다. 이 테스트만으로 STT 인식률이나 전체 LLM 품질을 보장하지 않습니다.

## 연결 구현 검증

- 백엔드 회귀 테스트 60개 통과. 외부 API 응답은 모의 처리했습니다.
- 실제 WebM/Opus → WAV 변환, Speech 업로드 계약, 인증·리다이렉트·빈 전사 오류를 검사했습니다.
- 음성 업로드 → 전사 → HCX 요약 초안 → 작성자 제출 → 가족 서재 공개를 격리 DB와 모의 API로 검증했습니다.
- Speech 키·Invoke URL 등록 화면과 음성 파일 테스트를 추가했습니다. 키는 아직 발급 전이므로 실제 STT 호출·음성 인식 품질은 미검증입니다. 모바일 녹음·백엔드 연결도 별도 작업입니다.
