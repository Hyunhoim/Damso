CLOVA Speech 설정

상태 확인 중

네이버 클라우드 콘솔 → CLOVA Speech → 장문 인식 도메인 → 빌더 → 설정 → 연동 정보에서 Secret Key와 Invoke URL을 확인해주세요. HCX-007 키와는 별도입니다.

URL 뒤에 /recognizer/upload는 붙이지 않습니다. 두 값 모두 서버의 비공개 설정 파일에만 저장합니다.

음성 파일로 STT → LLM 테스트

최대 10분·25 MiB. 선택한 음성이 CLOVA Speech로, 전사문이 HCX-007로 전송되며 각각 API 사용량이 발생합니다. 결과는 서재에 저장하지 않습니다. 테스트용 파일을 사용해주세요.
