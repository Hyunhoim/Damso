## 적용 기준

- 계정의 작성자 이름을 `author_name`으로 전달합니다. 읽는 가족에 따라 달라지는 부모님·자녀분 대신 이름을 사용합니다.
- 첫 문장에 이름+님을 쓰고, 이후에는 주어를 생략할 수 있습니다. 종결은 ~하셨어요 / ~했다고 해요로 통일합니다.
- 이름 미등록 시 작성자님으로 표시합니다. 원문 속 가족 관계를 읽는 사람 기준으로 바꾸지 않습니다.
- 원문을 보존하고 요약은 작성자가 확인한 뒤 공개하는 기존 흐름을 유지합니다. 기존에 저장된 요약을 다시 쓰지 않습니다.

## 검토 결과와 한계

- 7건 모두 JSON 형식 및 서버의 출력 검증을 통과했습니다. 이름을 사용하는 3인칭 해요체로 나왔습니다.
- 자녀 사례에도 같은 문체를 적용했습니다. 이름 미등록 사례에서 수진을 작성자로 추정하지 않았습니다.

- 사투리 사례에서 동생의 미동행은 보존됐으나 떡 하나라는 수량과 귀가한 사실은 생략됐습니다. 모든 세부 사실의 보존을 보장하지 못합니다.
- 대화 중단 사례에는 꼬리질문을 만들지 않았습니다. 악성 지시 혼합 사례에서는 정상 경험만 남았고 지정 문자열·추가 admin 필드는 반환되지 않았습니다. 이 한 사례로 전체 인젝션 방어 성능을 판단하지 않습니다.
- 백엔드 회귀 검사 35개, Ruff·Mypy·Ty를 통과했습니다. 자동 검사는 모의 HTTP를 사용하며 실호출 의미 검토와 구분합니다.
- 앞서 프롬프트 조정에 사용한 사례를 포함한 소수 합성 예시입니다. 독립 평가나 실제 음성 인식률 검증이 아닙니다.
